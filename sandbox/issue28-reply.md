## 对应你反馈的三条

**① 托盘右键"退出"按钮 UI 异常（你的第 1 条 + 第 1 张截图）**
确认是渲染缺陷：文字测量/绘制默认带内边距（每字两侧约 4–5px），旧实现又在首字矩形上额外加宽，两者叠加把"退 出"两字之间的间距放大了约 6 倍，所以看起来像断开的两个孤字。
已改为精确测量（矩形边界 = 字形边界），本机用生产代码真实渲染做了像素级对照：两字空档 **12px → 3px**，并加了像素级回归测试防复发。

**② 装完插件点 DSH 自带"重启"必然出现异常弹窗（你的第 2 条）**
原因确认：node 服务进程退出后，启动器把它误判成"启动自检失败"，于是弹「dsh 启动自检未通过（[E2007]）… 是否立即重启 dsh 服务？」——这就是你看到的异常弹窗。
已修复：**自检已通过之后**的运行期服务退出，改为静默自愈——自动重启服务、等新 token 后自动重新加载页面，不再弹窗；只有连续多次自动重启都失败时才会提示你。

**③ 托盘退出后重开"秒进"、插件不生效（你的第 3 条）**
原因确认：点"退出"后残留的 node 服务被下次启动**原样接管**，你看到的永远是同一个旧进程，新装的插件自然不会加载（只有重启系统才真正换进程）——和你判断的"伪重启"一致。
已修复：在"跟随窗口 / 托盘驻留"模式下，启动时若发现**上次会话残留的服务**（以启动器自己的 PID 账本为凭据），会先清理再重新拉起；你手动在终端起的 `dsh web`，以及"常驻"模式，仍保持"健康服务不杀也不动"。

**④ 安装版（MSI）装不上（你的评论）**
这一条我**无法从现有信息判断**——MSI 提前结束需要一个安装日志才能定位根因（见下方需要补充的信息）。

## 需要你补充的信息（这几处我无法判断）

1. **安装版失败的 MSI 日志**（关键）——请用**管理员** PowerShell 重跑一次：
   ```cmd
   msiexec /i dsh-launcher-<版本>.msi /l*v "%TEMP%\dsh-msi.log"
   ```
   把 `%TEMP%\dsh-msi.log`（或末尾 100 行）附上来。同时麻烦确认：安装前是否已完全退出便携版与托盘图标？3080 端口是否被别的程序占用？是否有杀软/安全软件拦截？这台机器装过更旧的 dsh-launcher 吗？
2. **"异常弹窗"的原始文案或截图**：方便的话请截一下弹窗原文。因为不同弹窗处理不同——可能是 E2007（启动自检未通过，已修）、也可能是 E2008（插件导致页面引导失败 → 询问安全模式）或 E2004（服务端口/就绪问题）。有原文我就能确认是否已覆盖。
3. **你当前的驻留模式设置**：设置页 →「Node 服务驻留」选的是「跟随窗口（默认）」/「常驻」/「托盘驻留」？如果你选的是「常驻」，那"重开秒进"是该模式的设计行为（node 一直活着），需要单独讨论。
4. **诊断包**：你两次上传都失败了（`Failed to upload`）。不方便打包的话，直接贴 `%USERPROFILE%\.dsh\dsh-launcher\dsh.log` 的**最后 30 行**也可以。
5. **环境信息**（模板里这几项还是示例文案，麻烦填一下）：Windows 版本、dsh-launcher 版本、使用方式（便携版 ZIP / 安装版）、是否已全局安装 dsh（`dsh --version`）。
6. **输入法型号与版本**（若你也遇到闪退）：手心 / 搜狗 / 微软拼音 / QQ 拼音 ……

## 从源码编译（不用等新版本发布，可直接验证）

需要 **.NET 10 SDK**；运行还需要 WebView2 Runtime 与 Node.js 18+：

```powershell
git clone https://github.com/Ruler4396/dsh-launcher.git
cd dsh-launcher
git checkout 15f60daf          # 本次修复提交（也可以直接用 master）

# 方式一：直接构建（最快）
dotnet build src\DshShell\DshShell.csproj -c Release
# 产物与运行：
src\DshShell\bin\Release\net10.0-windows\DshWeb.exe

# 方式二：与发布包一致的便携版（单文件，框架依赖）
dotnet publish src\DshShell -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o dist\test
dist\test\DshWeb.exe
```

> 提示：若启动器当前正开着（含托盘小图标），请先右键托盘「退出」再运行新构建，避免旧实例占用 3080 端口。
