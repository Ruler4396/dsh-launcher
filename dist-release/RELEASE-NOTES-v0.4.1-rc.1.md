## 🛠 修复

### 1. 首装（本机无 dsh）不再静默失败

- **首装改走 npm 全局安装** `@deepseek-ai/dsh`：单次安装、复用 npm 缓存，比旧 SelfContained
  双份构建更快更省 CPU/内存，也彻底避开 npx 冷解析反复下载。
- 跨镜像源共享总预算（600 秒，单源上限 420 秒），每个换源边界都会在启动画面显示黄色告警——
  降级过程全程可见，不再是"卡住不知道在干嘛"。
- **安装失败响亮停止**：弹 `[E1012]` 展示真实根因与手动修复命令
  （`npm install -g @deepseek-ai/dsh`），绝不再静默落入 npx 慢路径或无声退出。

### 2. "双击后没弹窗/无声消失"收口

- 第二实例等待主窗从 20 秒收紧到 5 秒；超时不再无声退出，而是弹 `[E1009]` 说明情况。
- 终态崩溃（未捕获异常）在非无头模式弹 `[E9001]` 对话框，展示异常摘要与统一日志路径——
  再也没有"程序消失了但什么都没发生"。

### 3. 点击很久才开窗 → 三处死窗期消除

- 就绪判定所需的 dsh 身份发现挪出 UI 线程（旧实现同步 spawn `node --version` 探测可阻塞数秒）；
- Splash 关闭后的重复端口终检删除、更新回滚武装移入后台线程——建窗前零额外阻塞；
- 版本探测改异步排空 + 超时杀整树（进程三必须合规）+ 会话级记忆化，同一探测不再反复起进程。

### 4. 其他

- 更新引擎的 staging 原子应用链路保持不变（本次只动首装路径，不动更新路径）。
- 单元测试禁用集合间并行，根治静态状态互踩导致的 CI 随机红。

## 📦 安装与卸载 / Install & Uninstall

**MSI 安装包（推荐新手）**：双击安装，向导里可勾选是否开机自启；自动创建桌面与开始菜单快捷方式。卸载：设置 → 应用 → dsh-launcher → 卸载。

**便携版 ZIP**：解压即用，双击 `DshWeb.exe`；删文件夹即卸载（自启/快捷方式用 `uninstall-autostart.cmd` 清理）。ZIP 为框架依赖发布，**解压后建议先运行同目录 `check-prereq.cmd` 确认已安装 .NET Desktop Runtime 10 与 Node.js 18+**（MSI 自带前置检查，无需手动）。

> MSI 与 ZIP 内容完全相同；区别只在安装方式。**从 v0.4.0 升级**：直接覆盖安装/解压即可，
> 用户数据（settings.json、日志等位于 `%USERPROFILE%\.dsh\dsh-launcher\`）不受影响。
