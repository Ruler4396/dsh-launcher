## 一句话总结

dsh 更新链路全面重构为「SelfContained 运行时原子交换」：下载秒级、构建 pnpm 加速、应用原子化、失败可回滚；同时启动器本体瘦身 26MB → 1.3MB，并修复一批影响日常使用的稳定性问题。

## 🚀 新特性

### 1. SelfContained 运行时原子交换（更新引擎重写核心）
- 启动器自管一份 dsh 运行时（`%APPDATA%\..\dsh-launcher\runtimes\<版本>`），更新不再依赖全局 npm 的安装状态
- 新版本在独立 staging 目录完整构建，成功后 `Directory.Move` **原子切换**——任何时刻断电/崩溃都不会留下半更新的运行时
- 构建失败自动清理 staging 并回退旧路径，当前会话不受影响

### 2. pnpm 机会主义加速 + 双引擎进度条
- 更新构建优先尝试 pnpm（热缓存约 10 秒完成），pnpm 缺失或失败自动回退 npm（约 60 秒）
- pnpm 路径解析 ndjson 安装事件，标题栏进度条显示**真实百分比**「已构建更新 x%（版本号）」；npm 路径退回跑马灯模式，不再显示伪百分比
- npm 执行引擎同步重写：node.exe 直接执行 npm-cli.js，彻底抛弃 cmd.exe /c 包装与 .cmd shim 编码陷阱（E4001 根因）

### 3. 首次运行快速引导（first-run provision）
- 全新机器首次启动不再走 npx 网络慢路径：自动 `npm pack` 秒级拉取 tarball → pnpm 快速安装 → 原子落盘到 runtimes 目录
- **本版修复其关键 Bug**：pnpm v11 将「包已装好、仅构建脚本被拦截」的退出标记写在 stdout（stderr 为空），旧实现只查 stderr 导致新环境首装必误判失败、白白落入慢速兜底。现改为双流判定，实测全新环境 pnpm 单次 21 秒直达服务就绪
- 同源机制也服务于 dsh 自动更新：toast 点击 → 静默下载+构建 → 下次启动原子应用，全程不打断使用

### 4. 后台静默下载 + 本地 tarball 直装
- 检测到 dsh 新版本后可静默预下载安装包到本地缓存，点击确认时直接本地直装，不再现场走网络

## 🔧 用户可感知的修复

### 启动与运行可靠性「三合一」
- **体积瘦身 26MB → 1.3MB**：弃用 windows10.0.19041 TFM 与 WinRT 投影 DLL（Microsoft.Windows.SDK.NET.dll），Toast 通知改用手写 combase 最小互操作；最低系统要求随之还原，不再强制 Win10 2004
- **E2008「启动异常」误报根治**：BootGuard 页面探针对 DOM 文本命中降级为 `dom-suspect` 计票制（连续多次 Absent 才报警）；仅 JS 错误通道保留一票否决。此前侧栏出现"plugin fatal"等字样的正常页面会被立即误判
- **E2005 关窗残留进程**：关窗停服务的进程终止改为全树强杀（taskkill /T 兜底），根除孤儿 node 进程占用端口
- **更新数据守卫（UpdateDataGuard）**：pending/staging 关键状态文件写入前快照、损坏可回滚，防半写状态导致更新流程卡死

### 更新体验
- rc 版本（如 0.1.0-rc.7）检测不到更新：版本比较改为完整 SemVer 规则（含 prerelease 分段比较）
- 更新进度条钉死 50% / 文案闪烁：pnpm 聚合器按 packageId 自归一化，不依赖硬编码包总数
- 更新结束无提示：成功/失败结论驻留标题栏 12 秒，失败路径全部显式收口并带 [E4001] 错误码
- 「点取消没反应」：阶段 0 的 npm 应用支持取消令牌联动进程树终止，取消即时生效
- 暂存目录残留 lockfile 导致的 pnpm 假成功：每次构建前强制清场
- pnpm 主目录游离工作区劫持：install 统一加 `--ignore-workspace`
- npm 源顺序反转为快源优先（npmmirror 打头），主源失败自动切镜像重试

### 启动/窗口/系统兼容
- IME 输入法崩溃（0xc0000005 ImmSetOpenStatus）修复
- 端口三重验证（TCP + 进程身份 + HTTP）识别僵尸服务并清理后重启；非 dsh 进程占用快速失败并报 E2004
- 僵尸 pid 接管竞态导致的证据污染（E2007 误报场景）收窄
- 日志文件改 FileShare.ReadWrite 打开，不再被外部工具锁死而静默丢日志；写入失败自动落 D:\Temp 备援
- 多显示器：跨虚拟屏最大化回归测试迁移 Headless 纯函数体系；Per-Monitor V2 DPI 下 WebView2 按真实 DPI 渲染（150% 缩放不再模糊）
- 150% 缩放 0px 无边框间隙契约锁定（UIA E2E 守护）

### 安全模式与插件生态
- 坏插件注入 → 安全模式全链路 E2E 验证通过（自动应答钩子 DSH_TEST_SAFE_MODE_ANSWER 支撑无人值守演练）
- 托盘图标交由 dsh-launcher-lifetime 插件管理，launcher 回归纯壳职责
- SelfContained 服务启动隐藏控制台窗口

## ⬆️ 升级说明

- **MSI**：双击安装，按机器级安装，自带前置检查（.NET 10 Desktop Runtime / WebView2）
- **ZIP**：解压后顶层为 `dsh-launcher-windows-0.4.0\` 版本文件夹（v0.4.0 起不再打散文件），整文件夹放置即可
- 从 v0.3.x 升级：直接覆盖安装，profiles 配置与已装插件不受影响
- 建议同时更新 dsh 本体至最新（启动器会在托盘气泡提示一键更新）
