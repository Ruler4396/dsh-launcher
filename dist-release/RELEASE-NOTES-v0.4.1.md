# dsh-launcher v0.4.1（重要稳定性更新）

> 发布日期：2026-08-24　|　上一正式版：v0.4.0

## 一句话总结

集中修复 v0.4.0 用户反馈的三个问题——**首装静默失败**、**Release 更新日志为空**、**点击后很久才开窗**；首装链路改为 npm 全局安装。dsh 更新引擎已通过真实网络全链路沙盒实测（下载→构建→应用→原子切换→新运行时可执行）。

## 🛠 修复与改进

### 1. 首装（本机无 dsh）改为 npm 全局安装，不再静默失败

- 首装直接 `npm install -g @deepseek-ai/dsh`：单次安装、复用 npm 缓存，比旧 SelfContained 双份构建更快更省资源；
- 跨镜像源共享总预算（600 秒 / 单源上限 420 秒），换源边界在启动画面显示黄色告警——降级全程可见；
- **安装失败响亮弹 `[E1012]`** 展示真实根因与手动修复命令，绝不静默落 npx 慢路径。

### 2. "双击后没反应/无声消失"全面收口

- 第二实例等待主窗从 20 秒收紧到 5 秒，超时弹 `[E1009]` 说明而非无声退出；
- 终态崩溃补 `[E9001]` 可见对话框（异常摘要 + 日志路径），再无"程序消失了但什么都没发生"。

### 3. "点击很久才开窗"——三处死窗期消除

- 就绪判定所需的 dsh 身份发现移出 UI 线程（旧实现同步探测可阻塞数秒冻结 Splash）；
- 删除 Splash 关闭后的重复端口终检、回滚武装移入后台——建窗前零额外阻塞；
- 版本探测改异步排空 + 超时杀整树 + 会话级记忆化，同一探测不再反复起进程。

### 4. 更新引擎质量加固

- 更新编排内核抽离为独立组件并以 **RealOS 全链路测试锁定**：真实 registry 拉版本 → npm pack → 双路径构建 → 原子切换应用 → 应用后运行时真实可执行；
- 进程级冷启动演练脚本（scripts/update-drill.ps1）随版发布；
- 单元测试禁用集合间并行，根治 CI 随机红；发布流水线新增 changelog 缺条目 fail-fast 闸门。

## 📦 安装与卸载 / Install & Uninstall

**MSI 安装包（推荐新手）**：双击安装，向导里可勾选是否开机自启；自动创建桌面与开始菜单快捷方式。卸载：设置 → 应用 → dsh-launcher → 卸载。

**便携版 ZIP**：解压即用，双击 `DshWeb.exe`；删文件夹即卸载（自启/快捷方式用 `uninstall-autostart.cmd` 清理）。ZIP 为框架依赖发布，**解压后建议先运行同目录 `check-prereq.cmd` 确认 .NET Desktop Runtime 10 与 Node.js 18+**（MSI 自带前置检查，无需手动）。

> **从 v0.4.0 升级**：直接覆盖安装/解压即可，用户数据（`%USERPROFILE%\.dsh\dsh-launcher\`）不受影响。
> 已安装 rc 预发布的用户：正式版直接覆盖安装即可。
